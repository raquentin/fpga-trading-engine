This site hosts documentation on [punt-engine](https://github.com/raquentin/punt-engine), a collection of open gateware and software for trading previously maintained by [Trading @ Georgia Tech](https://www.linkedin.com/company/tradingclubgt/posts/?feedView=all).

## Contributing

Begin by reading some of this site and looking through [open issues tagged "help wanted"](https://github.com/raquentin/punt-engine/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22).

If you have questions or want guidance, see [our Discord](https://discord.gg/2A2dpwfxBF).
